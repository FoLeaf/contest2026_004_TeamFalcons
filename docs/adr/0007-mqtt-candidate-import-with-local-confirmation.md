# MQTT候选接入与板端人工确认

状态：用户已选择MQTT传输及远控状态提示；本文记录的协议细节为设计草案，待实现和验收。

日期：2026-10-18。

## 决策

用户选择通过MQTT传输手册解析后的候选点表，板端状态栏提示远控中，异常与恢复交由开发助手设计。候选版本按最近一次编辑理解，每次修改产生新revision并使旧试读失效。该解释不指定现有文件或固件版本号。

手机PDF上传仍走受鉴权HTTPS接口。配置服务经专用MQTT主题发送候选、试读和查询请求，板端返回状态；远程部署使用TLS、设备鉴权与方向隔离的ACL。当前明文MQTT上报能力不等同于已支持候选接入。

候选始终先校验、试读，再展示结果并等待人工本地确认。MQTT没有远程apply或confirm，远控提示不代替确认，也不赋予板载Agent配置权限。采用独立远程候选与配置会话互斥，避免绕过NSH原有人工确认流程。

## 替代范围与限制

替代AGENTS V4/V6及手册中禁止MQTT传输候选的旧团队约束，仅开放本协议定义的确定性配置入口。原NSH仍是现行实现；不经RS485或第二路UART配置点表的限制保持。AI请求响应、语音、音频不因本决策获准走MQTT。

[ADR 0004](0004-ai-generated-configuration-requires-device-side-confirmation.md) 的人工确认要求、[ADR 0006](0006-mqtts-control-https-download-ota.md) 的OTA方案保持。0006中不开放MQTT候选的表述由本决策替代；OTA不提供配置通道。
