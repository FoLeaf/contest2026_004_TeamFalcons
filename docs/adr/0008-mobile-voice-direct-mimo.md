# ADR 0008：手机语音直连 MiMo

- 日期：2026-10-20
- 状态：用户已确认架构方向，待设计、实现和验收。
- 依据：用户明确更正手机语音直连 MiMo，不经过板载 ReAct。

## 决策

手机语音请求直接连接 MiMo，不转交板载 ai_agent / ReAct。板载 Agent 继续承担已有板端查询、告警解释与报告任务；RSP 响应优化仅覆盖板载请求链路，手机语音独立设计和验收。

手机录音、播放和主动开启会话的范围保持。具体采用何种 MiMo 语音接口、是否分别调用 ASR/TTS，须按接口能力另行设计，本决策不代表已验证任何服务能力。

## 数据与权限

手机巡检回答仍须依据目标网关的真实快照、告警、事件与报告，关联设备、采样时间及请求；过期或不可用的数据明确说明。设备数据如何提供给手机或 MiMo、绑定鉴权、凭证管理和会话接口均待设计，不默认新增板端工具入口或云侧代理。

语音不修改配置、不代确认、不写寄存器、不清告警、不控制输出。手机或 MiMo 不可用时，本地采集、规则告警和屏幕继续工作。MQTT 不承载 AI 请求响应或语音分片，旧 MQTT AI Bridge 不恢复。

## 影响

替代手册中手机语音进入板载 Agent 的目标设计，同步更新项目手册、开发规则、维护 TODO 和 RSP 规划。既有板端能力及历史验收证据不因此改变；本次只更新文档，不启动手机开发或修改固件。
